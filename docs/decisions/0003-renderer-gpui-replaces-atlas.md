# ADR-0003 — Renderer: GPUI text/paint replaces Atlas D3D11

- **Status:** proposed
- **Date:** 2026-10-26
- **Owner phase:** P10

## Context

Stub. WT renderer uses Atlas Engine (D3D11). The GPUI port replaces it with GPUI
text/paint primitives; parity = glyph/cell layout, attrs, cursor/selection semantics —
not shader bytes per byte. Retro/pixel-shader effects re-expressed where tractable or
waived with an ADR deviation row.

See owner phase for finalization.
